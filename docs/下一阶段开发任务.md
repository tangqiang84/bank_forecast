# 下一阶段开发任务

## 当前已完成

- Java 8 + Spring Boot 后端基础工程、Flyway 数据库迁移和租户鉴权。
- Vue 3 + TypeScript 前端登录、驾驶舱、银行账户和银行流水工作台。
- 银行流水 CSV 导入及导入任务记录。
- 合同、项目、合同应收计划数据库及合同 CSV 导入。
- 流水与应收 MVP 匹配，以及未知收款、部分收款、应收未收异常生成。
- P0 匹配结果确认与异常闭环（2026-09-09 验收通过）。

## 下一步优先级

### P0：匹配结果确认与异常闭环（已完成）

- 已增加匹配结果列表、候选依据和人工确认、拒绝接口。
- 已增加异常事项分派、备注、处理完成、关闭和操作日志接口。
- `suggested` 结果确认后才更新流水匹配状态和应收已收金额，拒绝不产生财务计账。
- 已增加重复运行幂等控制，避免同一流水重复生成匹配结果和重复计账。

验收结果：通过。用户可以查看候选依据并确认或拒绝匹配；异常按 `new -> in_progress -> resolved -> closed` 流转并记录操作日志；重复运行不会重复生成结果或重复计账。

已交付接口：

- `GET /api/v1/matching/results`
- `POST /api/v1/matching/results/{id}/confirm`
- `POST /api/v1/matching/results/{id}/reject`
- `GET /api/v1/matching/exceptions`
- `POST /api/v1/matching/exceptions/{id}/assign`
- `POST /api/v1/matching/exceptions/{id}/comment`
- `POST /api/v1/matching/exceptions/{id}/resolve`
- `POST /api/v1/matching/exceptions/{id}/close`
- `GET /api/v1/matching/exceptions/{id}/logs`

### P1：匹配准确性和导入质量

- 支持一笔流水对应多个应收节点的拆分匹配。
- 支持多笔流水合并匹配一个应收节点。
- 建立客户名称归一化和可配置相似度规则，减少简单字符串包含造成的误匹配。
- 合同 CSV 增加预校验、错误行下载、重复导入策略和导入摘要。
- 银行流水导入增加文件大小、行数、日期范围和金额边界校验。

验收标准：边界输入返回结构化错误，错误行可定位，重复导入不会产生重复业务数据。

### P1：财务对账和可追溯性

- 增加合同应收、银行流水、匹配结果、异常事项的关联详情页。
- 增加财务确认记录、确认人、确认时间和审计日志查询。
- 增加按租户、合同、项目、日期、状态的筛选和分页。
- 驾驶舱补齐应收总额、已收金额、逾期金额、异常数量等真实指标。

验收标准：每条匹配和异常都能追溯到原始流水、合同节点和操作人。

### P2：安全与投产准备

- 删除开发测试账号和本地凭据记录，禁止默认开发密码进入生产环境。
- 增加生产数据库配置、JWT 密钥轮换、密码重置和管理员初始化流程。
- 增加登录失败限流、审计日志脱敏、文件上传权限和敏感字段加密检查。
- 完善 CI：静态检查、依赖安全扫描、后端打包和前端构建。

验收标准：生产配置不含开发凭据，密钥从环境变量或密钥管理服务读取，安全扫描无高危问题。

### P2：分析与预测服务接入

- 明确 analytics 服务与 Java 后端的接口契约。
- 将历史流水、应收计划和匹配结果汇总为预测输入。
- 增加现金流预测结果落库、查询和失败重试机制。
- 前端增加预测结果、预测偏差和风险提示展示。

## 推荐开发顺序

1. 匹配结果人工确认/拒绝和异常处理闭环。
2. 匹配幂等、拆分/合并匹配和客户归一化。
3. 导入质量、筛选分页和财务对账详情。
4. 生产安全加固和 CI 完善。
5. analytics 预测服务正式接入。
